# Project User Stories - Taskify Mobile

This document outlines the core user stories implemented across the mobile application.

## 1. User Registration
* **As a** new user,  
* **I want to** create an account using my username, email, and password,  
* **So that** I can securely access the application.

## 2. User Login
* **As a** registered user,  
* **I want to** log into the application using my email and password credentials,  
* **So that** I can view my personalized dashboard and saved content.

## 3. Login/Signup Error Handling
* **As a** user,  
* **I want to** see clear error messages when my login or registration attempts fail due to incorrect credentials or missing fields,  
* **So that** I can correct my inputs and proceed.

## 4. Home Screen & Branding
* **As a** user,  
* **I want to** view a clean home screen featuring an app logo in the header and a feed of content,  
* **So that** I can easily identify the app and browse available items.

## 5. External API Integration
* **As a** user,  
* **I want the** application to fetch and display live data dynamically from an external API,  
* **So that** I always have access to up-to-date information.

## 6. Item Details & Navigation
* **As a** user,  
* **I want to** tap on any item from the main screen to navigate to a dedicated detail screen showing comprehensive information,  
* **So that** I can read deeper into specific items.

## 7. Local Storage Persistence
* **As a** user,  
* **I want my** data, preferences, and session credentials to be securely stored locally on my device using persistent storage,  
* **So that** my information is preserved even after closing the app.

## 8. Settings Menu Navigation
* **As a** user,  
* **I want to** access a settings menu via a navigation icon from anywhere in the app,  
* **So that** I can quickly navigate to preferences, profile options, and notifications.

## 9. Notifications Management
* **As a** user,  
* **I want to** configure my notification preferences and test alerts within the settings screen,  
* **So that** I can manage how and when the app notifies me.
